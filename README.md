# CRÓNICAS ANÓMALAS

Versión estática preparada para GitHub Pages.

## Estructura

- `index.html`
- `css/styles.css`
- `js/main.js`
- `js/animations.js`
- `data/articles.json`
- `favicon.svg`
- `robots.txt`
- `sitemap.xml`

No necesita Node, npm ni build step.

Importante: las imágenes de Wikimedia se cargan desde sus URLs de Commons. Los créditos y licencias se muestran dentro de cada expediente. Antes de publicar nuevos artículos, añade fuentes concretas y revisa la licencia de cada imagen.
